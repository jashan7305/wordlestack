# Guess word list

`guess_words.txt` contains 7,062 lowercase, ASCII five-letter entries generated from SCOWL 2020.12.07 with `perl mk-list american 70`, then filtered to five-character lowercase words and sorted. SCOWL's `american` category includes its English category. The word list is fixed in the application package and is never an answer source. NYT remains the sole source of daily solutions.
